# 🎓 Student Registration Form

## 📌 About the Project
This is a simple Student Registration Form created using HTML.  
It collects student details such as name, email, password, gender, skills, and date of birth.  
It also displays dummy student data in a table.

## ✨ Features
- 🧑 Full Name input
- 📧 Email input
- 🔒 Password field
- 👨‍🎓 Gender selection using radio buttons
- 💻 Skills selection using checkboxes
- 📅 Date of Birth selection
- ✅ Required field validation
- 📋 Student details displayed in a table

## 🛠️ Technologies Used
- 🌐 HTML5

## 📂 Project Contents
- `index.html` — Student Registration Form webpage

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Fill in the student details.
4. Click the **REGISTER** button.

## 🎯 Learning Outcomes
- Understanding HTML forms and input types.
- Learning radio buttons and checkboxes.
- Practicing HTML tables and labels.
- Using basic form validation.
